📋 Project Overview

What is this?

This is an advanced MLOps application that uses Convolutional Neural Networks (CNN) to automatically classify kidney CT scan images. The model has been trained on a comprehensive dataset of normal and tumor kidney scans to provide accurate predictions.

Technology Stack

TensorFlow 2.12VGG-16MLflowDVC

Built with TensorFlow, using VGG-16 transfer learning. Experiment tracking via MLflow and data versioning with DVC for complete reproducibility.

Model Performance

Our model has been rigorously trained and evaluated on kidney CT scan datasets achieving competitive accuracy scores. The model uses transfer learning from VGG-16 to leverage pre-trained weights.

How It Works

Upload a kidney CT scan image, and our AI model will analyze it instantly. The model processes the image and classifies it as either Normal kidney tissue or presence of Tumor, providing quick diagnostic support.

⚙️ ML Pipeline

Our automated 4-stage MLOps pipeline ensures reproducible and scalable model training

1

📥 Data Ingestion

Downloads and preprocesses kidney CT scan dataset from secure cloud storage. Organizes images into Normal and Tumor categories with automatic validation.

2

🏗️ Base Model Preparation

Loads pre-trained VGG-16 model with ImageNet weights. Removes classification layer and adds custom dense layers optimized for kidney disease classification.

3

🎯 Model Training

Trains the model with data augmentation, batch normalization, and optimized hyperparameters. Uses Adam optimizer with learning rate 0.001 for 9 epochs.

4

📊 Evaluation & Tracking

Evaluates model performance on test dataset. Logs all metrics and hyperparameters to MLflow for experiment tracking and reproducibility.
